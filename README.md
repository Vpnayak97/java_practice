## 💻 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Vpnayak97/java_practice.git
```

### Navigate to the Project

```bash
cd java_practice
```

### Compile a Program

```bash
javac FileName.java
```

### Run a Program

```bash
java FileName
```
